# 시연 영상 녹화 가이드 (3분 이내, 웹 화면)

규정(별지2): 편집된 홍보 영상보다 **실제 입력 → Agent 판단 → Tool 호출 → 결과**가 보이게 찍는다. 기술설명서의 Workflow와 같은 순서로 보여 준다.

## 녹화 전 준비

```bash
cd /home/cwmnp/contrilog
curl -s localhost:11434/api/version          # Ollama(로컬 LLM) 서버 확인
.venv/bin/python scripts/web_demo.py         # http://127.0.0.1:8790
```

- 원격 서버라면 VS Code 아래쪽 "포트" 탭에서 8790을 전달하고, 로컬 브라우저로 `http://localhost:8790`을 연다.
- 리허설을 한 번 한다: [새로 시작] → [자동 진행] → 승인 → 끝까지. (LLM 해석이 캐시되어 녹화 때 지연이 없다)
- 브라우저 확대 100~110%, 창 너비 1400px 이상. 시나리오: "① 업무 막힘 발견 → 지원 → 해결"(P002 웹훅 서명 오류), 해석기: "답장 해석: AI (Qwen3)". 시연 모드를 켜면 기술 ID가 숨겨지고 승인 버튼이 커진다.

## 주의

- 승인 버튼을 누르기 전에 1–2초 멈춰 "사람이 결정한다"는 점이 보이게 한다.
- 화면 속 수치와 발표자료 수치가 같아야 한다 (`reports/latest.md`).
- 터미널 버전이 필요하면 `.venv/bin/python scripts/demo.py --speed 1.2` (승인은 y 입력).
- "P002 · 배송 추적 지도 화면"은 단어 겹침 때문에 지원자를 잘못 고르는 한계 사례라 시연용이 아니다.
